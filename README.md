# Mihai Starpitu — Personal Site

A static portfolio site for Mihai Starpitu, freelance automation engineer in pharmaceutical production.

## Run locally

From the project directory, run:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173` in a browser.

The site is intentionally dependency-free and includes Home, About and Contact views, responsive styling, and direct email/LinkedIn links.
